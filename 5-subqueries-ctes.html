🧩 5 — Subqueries & CTEs

Nested Queries · WITH Clauses (CTEs) · When to Use Each

What Is a Subquery?

A subquery (or nested query) is a query written inside another query. It runs first, and its result is used by the outer query — as a filter value, a list, or a derived table.

SELECT name, total_spent
FROM customer_totals
WHERE total_spent > (
  SELECT AVG(total_spent) FROM customer_totals
);

Here, the inner query (SELECT AVG(total_spent) FROM customer_totals) runs first and returns a single number, which the outer query then compares against.

SELECT * FROM orders
WHERE customer_id IN (
  SELECT customer_id FROM customers WHERE country = 'US'

Common Table Expressions (CTEs) — the WITH Clause

A CTE is a named, temporary result set defined with WITH ... AS (...) that you can reference later in the query, just like a table. It makes complex queries far more readable by breaking them into logical steps.

WITH customer_totals AS (
  SELECT customer_id, SUM(amount) AS total_spent
  FROM orders
  GROUP BY customer_id
)
SELECT c.name, ct.total_spent
FROM customer_totals ct
JOIN customers c ON c.customer_id = ct.customer_id
WHERE ct.total_spent > (SELECT AVG(total_spent) FROM customer_totals);

CTEs can also be chained: WITH a AS (...), b AS (...) SELECT ... FROM b

Subquery vs CTE: When to Use Each

SubqueryCTE (WITH)
ReadabilityCan get messy when nested deeplyNamed, step-by-step — easier to read
ReusabilityMust repeat the same subquery if used twiceDefine once, reference multiple times
Best forSimple, one-off scalar/list checksMulti-step logic, breaking down complex queries
RecursionNot supportedSupported (WITH RECURSIVE) in many databases

Rule of thumb: if you'd need to explain your query in steps out loud, use a CTE for each step

Same Logic, Two Ways

❌ Nested Subquery (harder to read)

SELECT name FROM customers
WHERE customer_id IN (
  SELECT customer_id FROM orders
  GROUP BY customer_id
  HAVING SUM(amount) > (
    SELECT AVG(total) FROM (
      SELECT SUM(amount) AS total
      FROM orders GROUP BY customer_id
    ) t
  )
);

✅ CTE Version (clear steps)

WITH customer_totals AS (
  SELECT customer_id, SUM(amount) AS total_spent
  FROM orders GROUP BY customer_id
),
avg_spend AS (
  SELECT AVG(total_spent) AS avg_total FROM customer_totals
)
SELECT c.name, ct.total_spent
FROM customer_totals ct
JOIN customers c ON c.customer_id = ct.customer_id
CROSS JOIN avg_spend a
WHERE ct.total_spent > a.avg_total;

WITH avg_order AS (
  SELECT AVG(amount) AS avg_amount FROM orders
),
above_avg_orders AS (
  SELECT o.customer_id
  FROM orders o
  CROSS JOIN avg_order a
  WHERE o.amount > a.avg_amount
),
qualifying_customers AS (
  SELECT customer_id
  FROM above_avg_orders
  GROUP BY customer_id
  HAVING COUNT(*) >= 2
)
SELECT c.name
FROM customers c
JOIN qualifying_customers q ON c.customer_id = q.customer_id;
