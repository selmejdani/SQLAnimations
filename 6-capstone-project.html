🎓 6 — Capstone Project

Combining Filtering · Aggregation · Joins · Subqueries & CTEs on a Real-World Dataset

📦 The Dataset: Northwind-Style Sales Data

This capstone uses a simplified version of the classic Northwind sales dataset (also similar in spirit to Chinook). In the real world you'd download this from Kaggle or the official sample DB and load it into a SQL environment — here it's simulated in-browser so you can query it instantly with no setup.

Five related tables model a real sales business:

TableRepresentsKey columns
customersCompanies who place orderscustomer_id (PK), name, country, segment
employeesSales reps who process ordersemployee_id (PK), name, region
productsItems for saleproduct_id (PK), product_name, category, unit_price
ordersOne row per order placedorder_id (PK), customer_id (FK), employee_id (FK), order_date
order_itemsLine items within an orderorder_id (FK), product_id (FK), quantity, unit_price

What You'll Practice

Everything from 2–5 comes together here: WHERE/ORDER BY/LIMIT filtering, GROUP BY/HAVING aggregation, multi-table JOINs, and WITH CTEs / subqueries — used together to answer realistic stakeholder questions.

🧪 SQL Playground

Query the full 5-table dataset. Supports WITH CTEs (chainable), JOIN/LEFT JOIN/CROSS JOIN (multiple), scalar/list subqueries, WHERE, GROUP BY/HAVING, ORDER BY, LIMIT.


📋 10 Realistic Business Questions

Answer each question with a query in its box, run it, then jot your insight. Mark it done when you're satisfied — your progress is tracked below.

📄 Deliverable: Data Analysis Report

Imagine you're presenting these findings to a business stakeholder. Write an executive summary, then export the full report — including every query, result set, and insight from the Business Questions tab — as a single Markdown file.
