📈 3 — Aggregation

COUNT · SUM · AVG · MIN/MAX · GROUP BY · HAVING

Aggregate Functions

Aggregate functions collapse many rows into a single summary value. They're almost always paired with GROUP BY when you want a summary per group (e.g., per customer, per category) rather than one value for the whole table.

COUNT()

Counts rows. COUNT(*) counts all rows, COUNT(col) ignores NULLs.

SUM()

Adds up numeric values in a column.

AVG()

Calculates the mean of a numeric column.

MIN() / MAX()

Smallest / largest value in a column.
SELECT COUNT(*) AS total_orders,
       SUM(amount) AS total_revenue,
       AVG(amount) AS avg_order_value,
       MIN(amount) AS smallest_order,
       MAX(amount) AS largest_order
FROM orders;

GROUP BY

Splits rows into groups sharing the same value(s) in one or more columns, then applies aggregate functions per group instead of over the whole table.

SELECT customer_name,
       COUNT(*) AS orders_placed,
       SUM(amount) AS total_spent,
       AVG(amount) AS avg_order_value
FROM orders
GROUP BY customer_name;

Rule: every non-aggregated column in SELECT must appear in GROUP BY

HAVING

HAVING filters groups after aggregation — unlike WHERE, which filters individual rows before grouping. Use it when your filter condition involves an aggregate function.

SELECT category,
       SUM(amount) AS revenue
FROM orders
GROUP BY category
HAVING SUM(amount) > 500;
ClauseFiltersWhen it runs
WHEREIndividual rowsBefore grouping
HAVINGAggregated groupsAfter grouping

Putting it all together

SELECT category,
       COUNT(*) AS num_orders,
       SUM(amount) AS total_revenue,
       AVG(amount) AS avg_order_value
FROM orders
WHERE status = 'completed'
GROUP BY category
HAVING COUNT(*) >= 2
ORDER BY total_revenue DESC;

🎯 Practice Challenge 1: Average Order Value per Customer

Task: What's our average order value per customer?


Show solution 
SELECT customer_name, AVG(amount) AS avg_order_value
FROM orders
GROUP BY customer_name
ORDER BY avg_order_value DESC;

🎯 Practice Challenge 2: Best-Selling Product per Month

Task: Which products sell best per month (by units sold)?

Note: this uses a separate sample table, order_items — shown below.


Show solution 
SELECT month, product, SUM(units) AS units_sold
FROM order_items
GROUP BY month, product
ORDER BY month, units_sold DESC;

Then, per month, take the top row (highest units_sold) as the best seller.
