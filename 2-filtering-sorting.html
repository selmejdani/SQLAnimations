📊 2 — Filtering & Sorting

WHERE · Comparison Operators · AND/OR/NOT · ORDER BY · LIMIT

WHERE Clause

Filters rows based on a condition. Only rows where the condition is TRUE are returned.

SELECT * FROM orders
WHERE amount > 100;

AND / OR / NOT

Combine multiple conditions. AND requires all conditions true, OR requires at least one, NOT negates a condition.

SELECT * FROM orders
WHERE amount > 100
  AND status = 'completed'
  AND NOT country = 'FR';

Tip: use parentheses to control precedence, e.g. WHERE (a OR b) AND c

ORDER BY

Sorts result rows. Default is ascending (ASC); use DESC for descending. Can sort by multiple columns.

SELECT * FROM orders
ORDER BY amount DESC, order_date ASC;

LIMIT

Restricts the number of rows returned — useful for "top N" queries. Often paired with ORDER BY.

SELECT * FROM orders
ORDER BY amount DESC
LIMIT 10;

Putting it all together

SELECT customer_name, amount, order_date
FROM orders
WHERE amount > 100
  AND order_date >= DATE('now', '-30 days')
ORDER BY amount DESC;
